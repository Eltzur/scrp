# Israeli Price Comparison — Web Frontend

React + Vite + TypeScript + Tailwind UI for the Israeli supermarket price comparison API.

## Running locally

Both the backend and frontend must run simultaneously:

```bash
# Terminal 1 — backend (from project root)
uvicorn api.main:app --reload

# Terminal 2 — frontend
cd web
npm run dev
```

Frontend: http://localhost:5173
Backend: http://localhost:8000
API docs: http://localhost:8000/docs

## Building for production

```bash
npm run build      # outputs to web/dist/
npm run preview    # serve the built output locally
```

## TypeScript types

Types in `src/types/api.ts` are auto-generated from the backend's OpenAPI spec.
Regenerate whenever the backend models change (backend must be running):

```bash
npm run gen:types
```

## Type checking

```bash
npm run typecheck
```

## Project structure

```
src/
  api/
    client.ts       — axios instance + typed fetch functions
    hooks.ts        — TanStack Query wrappers (useSearch, useCompare, etc.)
  components/
    Header.tsx
    SearchBar.tsx   — debounced 300ms input
    Filters.tsx     — city dropdown, chain filter, compare mode toggle
    StatsBar.tsx    — live DB stats from /stats
    ResultsList.tsx — loading/error/empty state + responsive grid
    ProductCard.tsx — per-product card with cheapest-per-chain price rows
    EmptyState.tsx
    ErrorState.tsx
    LoadingSpinner.tsx
    ProductCardSkeleton.tsx
  types/
    api.ts          — generated by openapi-typescript, do not hand-edit
  App.tsx           — layout + search/filter state
  main.tsx          — QueryClient provider + React root
  index.css         — Tailwind directives only
```
