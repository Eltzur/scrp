# מסמך הגדרות מאגר — SUPER XXL / XXL

> **טיוטה (DRAFT) — לא ייעוץ משפטי.** נכתב ב-SU11A-49 (22 באוקטובר 2026) מתוך הקוד, `docs/store_privacy_inventory.md` ו-`docs/security/su11a48_security_review.md`. כל מקום שמסומן **לאימות** דורש בדיקה של Dude או יועץ לפני שהמסמך נחשב סופי. מענה לפער "מסמך הגדרות מאגר" בסקירת האבטחה SU11A-48.

| שירותים | SUPER XXL (אתר super.xxl.co.il, אפליקציית Android), פורטל xxl.co.il, XXL Flights (fly.xxl.co.il). חשבון משתמש אחד משותף לכל השירותים |

## 2. מטרות השימוש במידע

1. ניהול חשבון משתמש והתחברות (אימייל וסיסמה).
2. שמירת סלי קניות ומועדפים לבקשת המשתמש.
3. דירוגים וביקורות על מוצרים (מוצגים לציבור **ללא** זיהוי הכותב), ודיווח וחסימה של ביקורות.
4. ניהול תוכן (מודרציה): הסתרת תוכן פוגעני, טיפול בדיווחים, חסימת משתמשים מפרסום.
5. תיעוד הסכמה לתנאי השימוש.
6. מחיקת חשבון לבקשת המשתמש.
7. תפעול, אבטחה ומניעת שימוש לרעה (יומני שרת).
8. XXL Flights: חיפושים והתראות שמורים של משתמש מחובר (הטבלאות קיימות; **לאימות** אם יש בהן נתונים).

מידע המחירים והמוצרים (ממאגר שקיפות המחירים הממשלתי, GS1) אינו מידע אישי ואינו חלק ממאגר זה.

## 3. סוגי המידע ומקורו

| מידע | מקור | היכן נשמר |
|---|---|---|
| אימייל, גיבוב סיסמה (hash), מזהה משתמש (UUID), זמני התחברות | המשתמש, בהרשמה | Supabase Auth |
| יומני התחברות של Supabase (כתובת IP, user agent) | מכשיר המשתמש | Supabase — **לאימות: תקופת שמירה בתוכנית הנוכחית** |
| מזהה משתמש, אימייל, דרגה (tier), גרסת תנאי שימוש וזמן הסכמה, סימון חסימה (banned_at) | המשתמש / מנהל התוכן | Postgres, טבלה `users` |
| סלים שמורים (שם, ברקודים, כמויות) | המשתמש | `saved_baskets` |
| מועדפים (ברקודים) | המשתמש | `favorites` |
| דירוג 1–3 והערה (עד 2,000 תווים) | המשתמש | `ratings` |
| דיווחים על ביקורות (סיבה עד 1,000 תווים) | המשתמש / מסנן אוטומטי | `rating_reports` |
| חסימות (מי חסם את כותב איזו ביקורת) | המשתמש | `user_blocks` |
| רשומת מחיקה (UUID בלבד, ללא אימייל) | המערכת | `deleted_accounts` |
| הרשמה לעדכונים בפורטל (אימייל, ורטיקל, user agent, referrer) | המשתמש, באתר בלבד | Supabase, `portal_email_signups` |
| חיפושי טיסות והתראות | המשתמש | `flights.saved_searches`, `flights.alerts` |
| יומני שרת: כתובת IP, זמן, נתיב הבקשה כולל טקסט חיפוש וברקודים; ב-nginx גם user agent | מכשיר המשתמש | journald בשרת, יומני nginx |
| התראות מודרציה במייל: אימייל הכותב או המדווח, ההערה (עד 500 תווים) או סיבת הדיווח | המערכת | תיבת info@xxl.co.il (Hostinger) |

**לא נאסף:** שם, טלפון, כתובת, מספר זהות, אמצעי תשלום, מיקום מדויק (המיקום מחושב במכשיר ואינו נשלח; ב"סניפים קרובים בלבד" נשלחת רשימת מזהי סניפים בגוף הבקשה, ואינה נשמרת או נרשמת ביומן), היסטוריית חיפוש לפי משתמש.

## 4. מי ניגש למידע

| Dude (מפעיל יחיד) | שרת (SSH במפתח בלבד), מסד הנתונים, Supabase, Backblaze, Hostinger, Google Cloud, Play / EAS | **לאימות: רשימת הגישות והאם הוגדר אימות דו-שלבי (MFA) בכל קונסולה** |

אין העברת מידע לצדדים שלישיים מעבר לספקי השירות שבסעיף 5. אין מכירת מידע.
