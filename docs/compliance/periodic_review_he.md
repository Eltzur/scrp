## בדיקה רבעונית (כשעה)

- [ ] סריקת תלויות: `pip-audit` על חבילות השרת, `npm audit --omit=dev` באתר, באפליקציה ובאתר הטיסות. שדרוג ממצאים גבוהים.
- [ ] `apt list --upgradable` ואתחול אם ממתין עדכון ליבה.
- [ ] יומני nginx: דחיות קצב (`limiting requests`) — האם משתמשים אמיתיים נחסמים.
- [ ] journald: `query timeout`, שגיאות 5xx חוזרות.
- [ ] גיבוי אחרון קיים ב-B2 ובשרת (`rclone ls`, `ls -l /var/backups/scrp`).
- [ ] תור המודרציה ריק או מטופל.
- [ ] יומן האירועים מעודכן.

## סקירה שנתית (כחצי יום)

- [ ] כל סעיפי הבדיקה הרבעונית.
- [ ] **מסמך הגדרות המאגר** (`database_definition_he.md`): סוגי מידע, מטרות, ספקים, תקופות שמירה, מספר נושאי מידע — עדכון ותאריך.
- [ ] **נוהל האבטחה** (`security_procedure_he.md`): עדיין משקף את המצב בפועל.
- [ ] **רשימת גישות:** מי ניגש לשרת, למסד הנתונים ולכל קונסולת ספק; הסרת גישות שאינן נחוצות; MFA בכל חשבון.
- [ ] **בדיקת שחזור:** שחזור גיבוי למסד נתונים זמני ובדיקת ספירת שורות.
- [ ] **סודות:** האם יש מפתח שצריך להחליף (עזיבה, חשד, גיל).
- [ ] **סריקות:** gitleaks על היסטוריית המאגרים, bandit / semgrep על הקוד.
- [ ] **כותרות ו-TLS:** `curl -sI` לכל דומיין (HSTS, CSP, nosniff, X-Frame-Options, ללא גרסת שרת); תוקף תעודות.
- [ ] **הגדרות שרת:** `sudo sshd -T`, `sudo ufw status`, `ss -ltn` (5432 על localhost בלבד).
- [ ] **ספקים:** תנאי שירות / DPA בתוקף; אזור אחסון; האם נוסף ספק.
- [ ] **מדיניות הפרטיות** מול המצב בפועל (`docs/store_privacy_inventory.md`).
- [ ] **ספי תיקון 13** (`docs/compliance_amendment13.md`): מספר משתמשים מול 10,000 / 100,000.
- [ ] כתיבת סיכום קצר עם תאריך בקובץ זה (טבלת לוח הזמנים) ופתיחת משימות לממצאים.
